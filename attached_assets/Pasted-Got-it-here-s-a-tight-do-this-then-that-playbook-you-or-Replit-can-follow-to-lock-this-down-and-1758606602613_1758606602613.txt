3) Add the endpoints you were curling (optional but handy)

Your app already supports GET /api/availability (with required query params). You also tried /api/availability/rules and /api/availability/rules/active—those returned HTML because no routes matched. If you want these, add tiny read-only routes.

Create server/routes/availabilityRules.ts:

import { Router } from 'express';
import { Pool } from 'pg';

const router = Router();
const pool = new Pool({ connectionString: process.env.DATABASE_URL });

router.get('/rules', async (_req, res) => {
  try {
    const { rows } = await pool.query(
      `SELECT id, day_of_week, start_time, end_time, is_active
       FROM availability_rules
       ORDER BY day_of_week, start_time`
    );
    res.json({ rules: rows });
  } catch (err) {
    console.error('rules error', err);
    res.status(500).json({ error: 'Failed to load rules' });
  }
});

router.get('/rules/active', async (_req, res) => {
  try {
    const { rows } = await pool.query(
      `SELECT id, day_of_week, start_time, end_time
       FROM availability_rules
       WHERE is_active = true
       ORDER BY day_of_week, start_time`
    );
    res.json({ rules: rows });
  } catch (err) {
    console.error('active rules error', err);
    res.status(500).json({ error: 'Failed to load active rules' });
  }
});

export default router;


Wire it into your main API router (e.g., server/routes/index.ts):

import availabilityRules from './availabilityRules';

const api = Router();

api.use('/availability', availabilityRules);

// ...existing endpoints

4) How to call the existing availability endpoint correctly

Validation requires from, to, and either hours or serviceId. Example:

FROM=$(date -u +"%Y-%m-%dT00:00:00Z")
TO=$(date -u -d "+7 days" +"%Y-%m-%dT23:59:59Z")
SERVICE_ID="<put-a-real-service-id-here>"  # or use &hours=60

curl -s "http://127.0.0.1:5000/api/availability?from=$FROM&to=$TO&serviceId=$SERVICE_ID&timezone=America/New_York" | jq .


If you don’t have services, use hours:

curl -s "http://127.0.0.1:5000/api/availability?from=$FROM&to=$TO&hours=60&timezone=America/New_York" | jq .
