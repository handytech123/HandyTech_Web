TASK 1 — FIX ACTIVE SERVICE FILTER:

service.isActive ?? false

const isServiceActive = (service) =>
  service.isActive === true || service.active === true || service.isActive === undefined;

Use this helper anywhere services are filtered for display or booking.

TASK 2 — ADD HOMEPAGE DISPLAY CONTROL:

showOnHomepage boolean default true

Use it to control which active services display on the public homepage.

Requirements:
- Add showOnHomepage to services schema/model if needed.
- Add it to the admin service create/edit form as a toggle:
  “Show on Homepage”
- Default should be true.
- Existing services should behave as true unless explicitly false.

This means:
