- Do NOT break booking flow.

quickPickOrder ascending

- service.name
- optional starting price if available
- Book button

When clicked:
- open/scroll to booking form
- preselect that exact backend service

Use backend services only.

Display active services grouped into three columns:
A — Essential Repairs & Maintenance
B — Home Improvement & Remodeling
C — Specialized Installations & Tech Services

Each column should:
- be compact
- list service names
- optionally show short pricing text
- have each service clickable or have a Book button
- clicking a service preselects that exact backend service in booking

TASK 4 — BOOKING FORM:
Booking form service dropdown should use all active backend services.

Quick Pick clicks and A/B/C list clicks must pass the backend service id or exact backend service name, not hardcoded text.
