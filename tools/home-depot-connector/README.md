# HandyTech Home Depot Connector

This unpacked Chrome/Edge extension imports the lead currently visible in Pro Referral into the HandyTech admin system. Version 0.1 is deliberately observation-only: it never clicks Contact Now, spends points, or sends a customer message.

1. Open `chrome://extensions` or `edge://extensions`.
2. Turn on Developer mode.
3. Choose **Load unpacked** and select this directory.
4. Open the extension details, choose **Extension options**, and enter the site URL and server connector key.
5. Open an individual Pro Referral lead and click **Import visible lead**.

Do not add Home Depot credentials to this extension or the HandyTech server.
