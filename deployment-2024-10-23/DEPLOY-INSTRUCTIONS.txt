STEP-BY-STEP DEPLOYMENT INSTRUCTIONS
═══════════════════════════════════════════════════════════════════════════════

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STEP 1: ONE-TIME INITIAL SETUP (ONLY DO THIS ONCE)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1.1 - Install Node.js 20.x on VPS:
   curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
   sudo apt-get install -y nodejs

1.2 - Install PM2 globally:
   sudo npm install -g pm2

1.3 - Create directory structure:
   mkdir -p /var/www/handytech/{source,releases,shared}

1.4 - Clone GitHub repository (already done):
   cd /var/www/handytech
   git clone https://github.com/handytech123/HandyTech_Web.git source

1.5 - Create production .env file:
   nano /var/www/handytech/shared/.env

1.6 - Copy contents from .env.production (included in this package)
   Fill in all fields marked with 🔴

   REQUIRED FIELDS TO FILL IN:
   ✓ DATABASE_URL          - Your PostgreSQL connection string
   ✓ SESSION_SECRET        - Generate with: openssl rand -base64 32
   ✓ ADMIN_PASS           - Your strong admin password
   ✓ SMTP_PASS            - Your IONOS email password
   ✓ GOOGLE_CLIENT_ID     - From Google Cloud Console
   ✓ GOOGLE_CLIENT_SECRET - From Google Cloud Console
   ✓ GOOGLE_REDIRECT_URI  - https://your-domain.com/api/admin/google/callback

   OPTIONAL FIELDS:
   ✓ OPENAI_API_KEY       - For AI chatbot (fallback responses if not set)
   ✓ BREVO_API_KEY        - For marketing automation

1.7 - Copy deploy.sh to VPS:
   Upload deploy.sh (included in this package) to /var/www/handytech/deploy.sh
   Make it executable:
   chmod +x /var/www/handytech/deploy.sh

1.8 - Initial deployment:
   cd /var/www/handytech
   ./deploy.sh

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STEP 2: REGULAR UPDATES (USE THIS FOR EVERY UPDATE)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

2.1 - Push code changes from Replit to GitHub:
   (In Replit Shell)
   git add .
   git commit -m "Update description"
   git push origin main

2.2 - Deploy to VPS:
   (SSH into your VPS)
   ssh lou@74.208.149.78

   (Run deployment script)
   cd /var/www/handytech
   ./deploy.sh

That's it! The deploy.sh script will:
✓ Pull latest code from GitHub
✓ Create timestamped release
✓ Install dependencies
✓ Build application
✓ Restart with zero downtime
✓ Verify deployment
✓ Clean up old releases

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

❌ Problem: "DATABASE_URL environment variable is not set"
✅ Solution: Check /var/www/handytech/shared/.env exists and DATABASE_URL is set

❌ Problem: "tsx: not found" 
✅ Solution: Don't use npm run dev on VPS - use npm start (production mode)

❌ Problem: App won't start
✅ Solution: 
   1. Check logs: pm2 logs handytech
   2. Verify .env file: cat /var/www/handytech/shared/.env
   3. Check Node version: node --version (should be v20.x)

❌ Problem: Site can't be reached
✅ Solution:
   1. Check PM2 status: pm2 status
   2. Check health endpoint: curl http://localhost:5000/api/health
   3. Check firewall allows port 5000
   4. Verify nginx/apache reverse proxy if using one

❌ Problem: Old code still running after deploy
✅ Solution: The deploy.sh script uses PM2 reload for zero-downtime updates.
           If issues persist, try: pm2 delete handytech && ./deploy.sh
